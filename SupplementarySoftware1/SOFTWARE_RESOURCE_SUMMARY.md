# Software resource summary for v1.1.0

## Synthetic-curated demonstration

The legacy workflow remains reproducible and output-validated. It provides demonstration-level MFP-Score rankings, OPR suggestions, capillary-risk diagnostics, uncertainty labels, ablation/sensitivity summaries, manifests and checksums.

## Source-grounded evidence extension

The additive evidence extension contains 49 human-verified condition-level records from nine primary studies, descriptive source/outcome summaries, a manuscript-table generator, a nullable registry-to-model projection adapter and a neutral evidence workbook.

## Scoring boundary

The evidence extension is descriptive only. It produces no source-grounded MFP scores, OPR rankings, classifier training, accuracy/F1/AUPRC/calibration metrics or synthetic imputations. All evidence records remain `scoring_admitted = false`.

## Release state

Version v1.1.0 passed local integration, technical validation, human-verification checks and public-archive hygiene checks before tagging. The GitHub release is the immutable source snapshot used for Zenodo processing.
